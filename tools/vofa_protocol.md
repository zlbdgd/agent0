# 上位机调参协议与 3D 姿态可视化指南 (VOFA+)

在飞控开发过程中，肉眼无法直观评估滤波效果和 PID 响应，必须借助 PC 端上位机工具将数据绘制成实时波形或 3D 姿态模型。推荐使用免费开源的高性能调试上位机 **VOFA+**。

---

## 一、 VOFA+ 上位机配置

1. **下载与安装**：访问 [VOFA+ 官网](https://www.vofa.plus/) 下载 Windows 版本并安装。
2. **协议选择**：在左上角通信设置中选择 **FireWater** 数据协议。
3. **波特率设置**：选择飞控调试串口（如 USB-TTL 模块对应的 COM 口），波特率推荐设为 `115200` 或 `921600`。

---

## 二、 飞控端发送格式（FireWater 协议规范）

FireWater 协议是极简的 ASCII 文本流格式：多个浮点数用逗号 `,` 分隔，末尾加上换行符 `\n`。

### 1. 姿态角与期望角对比（用于调试角度环 PID）
飞控端串口输出代码示例：
```c
/* 输出: Roll实测, Roll期望, Pitch实测, Pitch期望 */
printf("%.2f,%.2f,%.2f,%.2f\n", 
       g_ahrs.roll, target_roll_angle, 
       g_ahrs.pitch, target_pitch_angle);
```

### 2. 原始角速度与滤波后角速度对比（用于调试低通滤波截止频率）
```c
/* 输出: 原始GyroX, 滤波后GyroX */
printf("%.2f,%.2f\n", g_imu.gyro_dps[0], filtered_gx);
```

### 3. 四元数 3D 姿态映射控件
在 VOFA+ 中添加 **3D 姿态显示控件**，控件数据输入选择由飞控发送的 4 个四元数数值：
```c
/* 输出: q0, q1, q2, q3 */
printf("%.4f,%.4f,%.4f,%.4f\n", 
       g_ahrs.q0, g_ahrs.q1, g_ahrs.q2, g_ahrs.q3);
```
晃动手中的飞控板，上位机屏幕中的 3D 飞机模型将丝滑无延迟地同步旋转！

## 三、 PID 参数在线调校口诀

```
+-------------------------------------------------------------------+
| 现象                              | 调节策略                      |
+-------------------------------------------------------------------+
| 飞机回正慢，像棉花糖，打杆迟钝    | 逐步增大内环 P                 |
| 悬停或打杆时出现高频剧烈震荡抖动  | 内环 P 过大，调小 P，或微增 D   |
| 电机空转温热甚至发烫              | D 增益过高或陀螺仪未加低通滤波 |
| 偏航轴打杆后有轻微回弹            | 适当增大 Yaw 轴的 P，增加 I 项 |
| 大油门爬升时机头自动上仰或下沉    | 增加外环/内环的 I 项以抵抗气动阻力 |
+-------------------------------------------------------------------+
```
