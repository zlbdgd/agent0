# 自研穿越机飞控（FC）元器件选型与 BOM 清单

本文档提供自研 STM32F405 飞控主板的 PCB 贴片/手焊元器件清单，以及整机所需外围航模动力配件的选型指导。

---

## 一、 自研飞控板（FC）板载器件清单

> **设计规格**：标准 20mm × 20mm (M2孔) 四层板，板载 STM32F405 + ICM-42688-P + 3.3V LDO + Type-C + 蜂鸣器驱动 + 遥控与电调焊盘。

| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | **主控芯片 (MCU)** | **STM32F405RGT6** (LQFP-64) | 1 | 168MHz 主频，1MB Flash，192KB SRAM，带硬件浮点 FPU，飞控算法算力充沛 | C15840 |
| 2 | **6轴 IMU 传感器** | **ICM-42688-P** (QFN-24 3x3mm) | 1 | 现代穿越机标配，超低噪声陀螺仪+加速度计，支持高速 SPI 通信 (最高 24MHz) | C2838382 |
| 3 | **3.3V 超低噪声 LDO**| **ME6211C33M5G** 或 **RT9193-33** (SOT-23-5) | 1 | 输出 3.3V/500mA，高 PSRR，专为 MCU 与 IMU 供电 | C82942 / C37537 |

## 二、 机架与动力系统外购清单（整机配套）

为配合这块 20x20mm 自研飞控，推荐选配以下安全耐摔的 2寸 涵道动力配件：

| 类别 | 推荐规格与型号 | 参考价格 | 说明 |
| :--- | :--- | :--- | :--- |
| **机架** | **2寸 涵道圈圈机架** (如 Beta85X /类似 85mm 碳纤塑料复合机架) | ￥35 ~ 50 | 全包涵道圈，室内试飞即使撞击也不会伤人和打碎螺旋桨 |
| **电机** | **1103 或 1202.5 无刷电机 (8000KV~11000KV)** × 4 | 约 ￥120 (4个) | 适配 2S 动力锂电池，出轴通常为 1.5mm |
| **电调** | **20x20mm 孔距 4合1 无刷电调 (12A~20A, BLHeli_S)** | ￥80 ~ 110 | 必须带标准 8-Pin 线材或焊盘，提供 5V BEC 供电和电流计输出 |
| **螺旋桨** | **2寸 3叶或4叶桨 (1.5mm轴径，多备几对正反桨)** | ￥15 (4对) | CW (正桨) × 2对 + CCW (反桨) × 2对 |
| **电池** | **2S 450mAh ~ 650mAh 75C LiPo 动力电池** × 2 | ￥35 / 块 | 接口通常为 XT30 插头 |
| **平衡充** | **ToolkitRC M4AC** 或 **简易 2S 平衡充电器** | ￥60 ~ 90 | 必须是专用锂电平衡充电器，切勿使用普通直流稳压源直接充锂电 |
